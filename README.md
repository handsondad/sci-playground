# 🔬 科学小游戏大冒险

在线访问：<https://handsondad.github.io/sci-playground/>

以 `fourier-puzzle-game` 的绘本互动样式与「小念和爸爸」双人启发式对话形式打造的**动手科学工程博物馆**，吸收了 **PhET Interactive Simulations**、**旧金山探索馆（Exploratorium Science Snacks）**、**Mathigon Polypad**、**HHMI BioInteractive**、**NASA Space Place** 与 **CS Unplugged** 的经典互动实验精髓。全馆按对称均衡的 **3×3 九大 STEAM 科学工程展厅**布局，共收录 **48 个可动手操作的互动实验台**（每馆 5~6 个，总计 **570 颗探索勋章**），外加 **27 张科学史大师故事与居家小实验百宝箱** 及 **30 篇「小念问爸爸」语音问答**：

- **➗ 数学思维馆（6 个实验）**：一笔画（欧拉路径）、汉诺塔（递归）、三扇门（蒙提霍尔概率与百次模拟）、筛质数寻宝（埃拉托斯特尼筛法）、四色地图（四色定理相邻染色）、向日葵螺旋（137.5° 黄金角与斐波那契叶序）
- **💡 声光电磁馆（6 个实验）**：拼波实验室（泛音与傅里叶合成）、镜子迷宫（反射定律）、三原色舞台灯（RGB 色光加色混合与彩色影子）、浮起来的鸡蛋（阿基米德浮力与密度）、摆的秘密（伽利略单摆等时性）、点亮小灯泡（串并联电路与短路排险）
- **⚙️ 机械动力馆（5 个实验）**：最快的滑梯（摆线与最速降线）、跷跷板平衡（杠杆力矩平衡）、扔得最远（抛体运动轨迹）、齿轮变速箱（齿数比、扭矩与惰轮转向）、滑轮起重机（定滑轮与动滑轮组省力费距离）
- **🏛️ 建筑结构馆（5 个实验）**：造桥大师（三角形刚性桁架与造价挑战）、罗马石拱门（楔形拱顶石与飞扶壁推力）、积木悬空桥（调和级数重心无胶悬挑）、摩天楼抗震（避开共振、隔震垫与台北 101 调谐阻尼球）、冬暖夏凉挑檐（太阳高度角被动式遮阳采光）
- **🧪 化学分子馆（6 个实验）**：调酸碱（0~14 彩虹指示剂）、配平方程式（质量守恒原子珠）、杯中彩虹（五层液体密度塔）、小苏打气球（限量反应物）、焰色烟花秀（本生灯金属离子发射光谱与双色礼花）、三态微观镜（水、低熔点金属镓与液氮的分子热运动相变）
- **🌿 生命科学馆（5 个实验）**：碱基配对（DNA 互补与氢键）、谁吃谁（食物链与十分之一能量金字塔）、裸蛋喝水（半透膜渗透作用）、孟德尔种豌豆（2×2 庞氏棋盘格与隐性性状隔代重现）、桦尺蠖捉迷藏（工业黑化与自然选择演化）
- **🌍 地球地理馆（5 个实验）**：等高线登山（地形剖面与陡缓坡判读）、板块构造局（俯冲海沟、褶皱造山与洋中脊扩张）、迎风坡与焚风（地形雨凝结潜热与雨影荒漠）、地层寻化石（地层叠覆律与岩脉切割律）、海陆风向标（海陆比热容差异与昼夜热力环流）
- **🪐 天文宇宙馆（5 个实验）**：月相（轨道几何与望远镜视野）、谁在过夏天（23.5° 地轴倾角与南北半球四季）、行星赛跑（开普勒第三定律 $T^2 = a^3$）、牛顿大炮（第一宇宙速度环绕与第二宇宙速度逃逸）、日食与月食（本影伪本影与 5° 白道倾角食季）
- **💻 计算逻辑馆（5 个实验）**：二进制灯牌（位权编码、单手数到 31 与点阵像素画）、逻辑门机关（AND/OR/NOT/XOR 布尔电路与真值表）、凯撒密码盘（双环移位加密与字母频率分析破译）、天平找次品（信息论三分查找法）、最短寻宝路（加权图与 Dijkstra 最短路径算法）

每个实验都包含多关卡挑战、语音朗读（Web Speech `zh-CN`）、微调滑块、原理提示与跨站持久化的三星勋章系统（`localStorage`），并在馆内配有「小念问爸爸」科学问答卡。

## 新增一个游戏

1. 在 `src/games/<门类>/<名字>/` 下编写纯函数 `logic.ts` 与组件 `index.tsx`（声明 `meta` 含 `maxStars`）。
2. 在 `src/catalog/games.ts` 的 `games` 数组中登记一行即可自动接入首页筛选、对应展厅与总星数统计。

## 本地运行与测试

```bash
npm install
npm run dev
npm test
npm run build
```

## 部署到 GitHub Pages

推送到 `main` 分支后，`.github/workflows/deploy.yml` 会自动执行 `npm ci`、`npm test`、`npm run build` 并发布到 GitHub Pages（仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**）。
