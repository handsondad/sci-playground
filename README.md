# 🔬 科学小游戏大冒险

以 `fourier-puzzle-game` 的绘本互动样式与「小念和爸爸」双人启发式对话形式打造的**动手科学馆集合**，并吸收了 **PhET Interactive Simulations**、**旧金山探索馆（Exploratorium Science Snacks）**、**Mathigon Polypad**、**HHMI BioInteractive** 与 **NASA Space Place** 的经典互动实验精髓。全馆分为五大展厅、共 **28 个可动手操作的科学小实验**（总计 **330 颗探索勋章**），外加 **15 张科学史大师故事与居家小实验百宝箱** 及 **18 篇「小念问爸爸」语音问答**：

- **➗ 数学馆（5 个实验）**：一笔画（欧拉路径）、汉诺塔（递归）、三扇门（蒙提霍尔概率与百次模拟）、筛质数寻宝（埃拉托斯特尼筛法）、四色地图（四色定理相邻染色）
- **🧲 物理馆（8 个实验）**：最快的滑梯（摆线与最速降线）、拼波实验室（泛音与傅里叶合成）、镜子迷宫（反射）、浮起来的鸡蛋（浮力与密度）、摆的秘密（单摆等时性）、扔得最远（抛体运动）、跷跷板平衡（阿基米德杠杆力矩）、三原色舞台灯（RGB 色光加色混合与彩色影子）
- **🧪 化学馆（6 个实验）**：调酸碱（0~14 彩虹指示剂）、配平方程式（质量守恒原子珠）、杯中彩虹（五层液体密度塔）、小苏打气球（限量反应物）、焰色烟花秀（本生灯金属离子发射光谱与双色礼花）、三态微观镜（水、低熔点金属镓与液氮的分子热运动相变）
- **🌿 生物馆（5 个实验）**：碱基配对（DNA 互补与氢键）、谁吃谁（食物链与十分之一法则）、裸蛋喝水（半透膜渗透作用）、孟德尔种豌豆（2×2 庞氏棋盘格与隐性性状隔代重现）、桦尺蠖捉迷藏（工业黑化与自然选择演化）
- **🌙 天文馆（4 个实验）**：月相（轨道几何与望远镜视野）、谁在过夏天（23.5° 地轴倾角与南北半球四季）、行星赛跑（开普勒第三定律 $T^2 = a^3$）、牛顿大炮（第一宇宙速度环绕与第二宇宙速度逃逸）

每个实验都包含多关卡挑战、语音朗读（Web Speech `zh-CN`）、微调滑块、原理提示与跨站持久化的三星勋章系统（`localStorage`），并在馆内配有「小念问爸爸」科学问答卡。

## 新增一个游戏

1. 在 `src/games/<门类>/<名字>/` 下编写纯函数 `logic.ts` 与组件 `index.tsx`（声明 `meta` 含 `maxStars`）。
2. 在 `src/catalog/games.ts` 的 `games` 数组中登记一行即可自动接入首页筛选、对应展厅与总星数统计。
