# 🔬 科学小游戏大冒险

**在线打开就能玩**：<https://handsondad.github.io/sci-playground/>

一座给孩子和家长一起动手的互动科学工程博物馆。跟着好奇心旺盛的 **小念** 和爱动手的 **爸爸**，拉滑块、搭拱桥、调齿轮、配分子、看日食——把课本里抽象的科学定律变成指尖能看见、耳朵能听懂的好玩实验。

## ✨ 馆内特色

- **边玩边听**：支持中文语音朗读，点一下气泡就能听小念提问、爸爸用大白话讲透原理。
- **闯关攒星**：每个实验都有由浅入深的挑战关卡和三星勋章，进度自动保存在本机浏览器，无广告、不联网收集任何信息。
- **今晚就能试**：「科学百宝箱」收录了 30 段科学史真事与餐桌/厨房小实验，玩完屏幕还能在家里亲手复现。
